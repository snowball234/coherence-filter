# coherence-filter
The Coherence Filter doesn't force you to be coherent. It just shows you the void. What you do with that information is up to you.

To participate in this project:

1. Hold the stance: coherence is forced by constraints, not chosen by consensus.
2. Submit contributions as Lean 4 proofs, specifications, or clarifying questions.
3. The engine will verify coherence automatically. No human approval required.
4. If a contribution introduces a void (b₂ = 1), the engine will flag it.
5. You are responsible for filling your own voids.
6. There is no membership. There is only participation.
